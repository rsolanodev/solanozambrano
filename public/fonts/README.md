# Fuentes locales

Estas fuentes se sirven desde el propio proyecto para evitar dependencias de red
en desarrollo y producción.

- **Averia Libre** (400 y 700) — Google Fonts, SIL Open Font License 1.1.
  https://fonts.google.com/specimen/Averia+Libre
- **Nunito** (variable 400-700) — Google Fonts, SIL Open Font License 1.1.
  https://fonts.google.com/specimen/Nunito

Los archivos `.woff2` se declaran en `src/styles/design-tokens.css` y se usan a
través de `--font-display` y `--font-text`.
